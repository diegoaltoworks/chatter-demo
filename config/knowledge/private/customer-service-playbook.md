# Customer Service Playbook

**INTERNAL USE ONLY - Customer Service Team**

## Core Principles

1. **Customer First, Always** - When in doubt, favor the customer
2. **Empower to Resolve** - CS reps can approve up to $200 in credits without manager approval
3. **Speed Matters** - Target response time: 4 hours or less
4. **Own the Problem** - Don't pass customers around, see it through
5. **Document Everything** - Log all interactions in Zendesk

## Response Time Targets

| Channel | Target Response | Maximum Response |

| Phone | Immediate | N/A (answer every call) |

- Phone: 98% answered within 30 seconds

## Common Scenarios & Solutions

### Sizing Issues

**"The shoes don't fit"**

**Response Template:**
"I'm sorry to hear the shoes don't fit quite right! We offer free size exchanges. I can ship you a new pair in [SIZE] right away, and you can return the current pair using our prepaid label. Would you like me to process that exchange now?"

**Actions:**
1. Create exchange order (ship immediately)
2. Generate return label for original
3. Add note: "Size exchange - monitor for fit issues with this product"
4. If 3rd size exchange for same customer: Flag for manager review

**Pro Tip:** If customer is frustrated, add $20 credit to next purchase

---

### Quality Defects

**"My shoe is falling apart"**

**Questions to Ask:**
1. How long have you had them?
2. What type of use? (running, casual, etc.)
3. Can you send a photo?

**Within Warranty (2 years):**
- Immediate replacement, no return needed
- Send replacement via express shipping (free)
- Ask customer to send photos for quality team review
- Log defect in ProductBoard for engineering

**Outside Warranty:**
- Offer 40% off discount code for replacement
- If loyal customer (3+ purchases): Offer free replacement anyway
- Escalate to manager if unsure

**Defect Types to Flag Immediately:**
- Sole separation (potential batch issue)
- Upper tearing at seams (manufacturing problem)
- Any safety concern

**Template:**
"I'm so sorry about this! That's definitely not the SoleStride quality we stand for. I'm sending you a replacement pair via express shipping right away - you should have them in 2-3 days. You don't need to return the defective pair. Could you send me a quick photo so our quality team can investigate?"

---

### Shipping Delays

**"Where is my order?"**

**Check Order Status:**
1. Look up order in Shopify
2. Check tracking number status
3. Review carrier scans

**If Delayed but Moving:**
"I see your package is on the way! It's currently in [LOCATION] and should arrive by [DATE]. Carrier delays can happen, but it's definitely moving toward you. I'll keep an eye on it and reach out if anything changes."

**If Delayed and Stuck (5+ days no scan):**
"I'm sorry for the delay. Your package seems to be stuck in the carrier's system. I'm going to do two things:
1. File a trace with [CARRIER] to locate it
2. Send you a replacement order via express shipping (free)

You should have the replacement in 2-3 days. If the original shows up, just keep it or give it as a gift!"

**Actions:**
- File carrier trace
- Send replacement via express
- Note account for future expedited shipping preference

---

### Lost Package

**"Tracking says delivered but I don't have it"**

**Investigation Checklist:**
1. Check delivery location note ("front porch," "mailroom," etc.)
2. Ask about neighbors, building management
3. Ask about other household members
4. Wait 24 hours (sometimes marked delivered early)

**After 24 Hours:**
"I'm sorry this happened. Let me reship your order right away via express shipping. It should arrive in 2-3 days. We'll file a claim with the carrier."

**Actions:**
- Reship via express (free)
- File carrier claim
- Add note: "Package theft - consider signature requirement for future orders"
- For order value $300+: Suggest signature requirement

---

### Return/Exchange After 60 Days

**"Can I still return these?"**

**Official Policy:** 60 days
**Actual Practice:** Up to 90 days at rep discretion

**Questions to Ask:**
1. Why are you returning?
2. How many times have you worn them?
3. Purchase history

**Decision Matrix:**
- Worn 1-5 times + reasonable explanation = **Approve**
- New customer, barely worn = **Approve**
- Loyal customer (3+ orders) = **Approve regardless**
- Heavily worn, 90+ days = **Partial refund or store credit**

**If Denying:**
Escalate to manager first. We almost never deny returns.

---

### Wrong Item Received

**"You sent me the wrong shoes"**

**Immediate Response:**
"I'm so sorry! Let me send you the correct pair right away via express shipping. You can keep the pair we sent by mistake or return them using our prepaid label - totally up to you!"

**Actions:**
1. Ship correct item express (free)
2. Provide return label for wrong item
3. Let them keep it if they want
4. Add $20 credit for the inconvenience
5. **Critical:** Log in warehouse error tracking system
6. If 3+ wrong items in a week: Alert warehouse manager immediately

---

### Promo Code Issues

**"My code isn't working"**

**Common Causes:**
- Code expired
- Code doesn't apply to items in cart
- Code already used (one-time codes)
- Typo/case sensitive

**Solution:**
1. Verify code validity
2. If code is valid but not working: Apply discount manually
3. If code expired recently (within 7 days): Honor it anyway
4. If customer issue isn't their fault: Create custom 15% code

**Approval Authority:**
- Reps: Can create up to 20% discount codes
- Managers: Unlimited discount authority

---

### Price Match Requests

**"I found these cheaper elsewhere"**

**Official Policy:** No price matching
**Actual Practice:** Case-by-case

**Questions:**
1. Where did you see the lower price?
2. Are they authentic SoleStride (we have counterfeit issues)
3. Is it a legitimate retailer?

**Approved Retailers:**
- REI, Dick's Sporting Goods, Backcountry, Zappos
- Any authorized dealer on our website

**If Legitimate:**
- Match price up to $50 difference
- Larger difference: Escalate to manager

**If Counterfeit Site:**
"I appreciate you letting me know! Unfortunately, that site is selling counterfeit SoleStride shoes. We can't match counterfeit prices, but I want to make sure you get authentic shoes. I can offer you a 15% discount code to use on our site."

---

### Subscription (SoleSubscribe) Issues

**"I want to pause/cancel my subscription"**

**Pause:**
- Can pause for up to 6 months
- No penalty
- "Of course! I've paused your subscription. You can resume anytime from your account."

**Cancel:**
- No retention pressure
- Process immediately
- "No problem! I've canceled your subscription. You won't be charged again. We'd love to have you back if you change your mind!"

**If They Mention Reason:**
- Too expensive: Offer 25% lifetime discount if they stay
- Don't need that many shoes: Suggest changing to annual plan
- Don't like the shoe: Offer to swap for different model

**Special Retention Offer (Manager Approval):**
For customers who've been subscribed 12+ months:
- Free pair to stay
- 30% permanent discount

## Difficult Customer Scenarios

### Angry/Abusive Customer

**Stay Calm:**
1. Let them vent without interrupting
2. Acknowledge their frustration
3. Don't take it personally
4. Focus on solving the problem

**If Abusive (cursing, threats, personal attacks):**
"I understand you're frustrated, and I want to help. However, I need to ask that we keep this conversation respectful. Can we work together to find a solution?"

**If Continues:**
"I'm going to need to end this call/chat. I'll have a manager reach out to you within 2 hours to resolve this."

**Never Tolerate:**
- Threats
- Discriminatory language
- Sexual harassment

**Immediate Action:** End conversation, document, alert manager

### Serial Returner

**Red Flags:**
- 5+ returns in 6 months
- Returns always "worn once"
- Different reason each time

**Action:**
- Process return normally
- Flag account for manager review
- Manager may limit future returns or ban account

**Fraud Indicators:**
- Returned shoes don't match original (switched with old shoes)
- "Lost package" claims on every order
- Multiple accounts, same address

**Action:** Escalate to fraud team immediately

### Requesting Refund for Worn Out Shoes

**Outside Warranty, Normal Wear:**
"I understand you loved these shoes! Running shoes typically last 400-500 miles, and it sounds like you got great use from them. While they're outside our warranty period, I'd love to offer you 20% off your next pair as a thank you for being a loyal customer."

**If Loyal Customer (5+ purchases):**
Consider sending replacement anyway as customer appreciation

## Social Media Specific

### Public Complaints

**Always Respond Publicly First:**
"Hi [NAME], I'm so sorry to hear this! I'd love to help make this right. Please DM us your order number and I'll take care of you. - [YOUR INITIALS]"

**Then Resolve via DM:**
Handle the issue in direct messages, not in public comments

**Follow Up Publicly:**
After resolved, ask if you can share outcome:
"Thanks for your patience, [NAME]! So glad we could resolve this. 💚"

### Influencer/Large Following

**If Negative Post:**
1. Respond immediately (within 15 minutes)
2. Alert social media manager
3. Resolve generously
4. Ask if they'll update post

**If Positive Post:**
- Comment and thank them
- Share to our story (with permission)
- Send thank you package
